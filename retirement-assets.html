모듈 3 ▼

퇴직연금자산 대사

시산표 vs 청구서 자동 대조

차액 자동 계산

For 각 연금사:
    시산표_잔액 = VLOOKUP(연금사, 시산표)
    청구서_잔액 = VLOOKUP(연금사, 청구서)
    
    차액 = 시산표_잔액 - 청구서_잔액
    
    If 차액 ≠ 0:
        → 차액 열에 표시
        → 노란색 배경

자동 서식

  • 차액 발생 행: 노란색 배경
  • 금액 형식: 회계
  • 정렬: 연금사명 기준
