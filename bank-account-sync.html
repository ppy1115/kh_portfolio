HOW IT WORKS / 작동 단계

1

정기 수집

5분마다 최근 3일을 겹쳐 조회합니다. 부팅 직후와 매일 새벽에는 최근 7일을 다시 보정합니다.

수집기 > 5분 스케줄러
2

에러 판정

실패를 예외 대신 응답 속 음수 코드로 돌려주는 API 특성에 맞춰, 세 가지 실패 형태를 한 함수에서 잡습니다.

API 클라이언트 > errors
3

중복 없는 적재

거래 고유키에 UNIQUE를 걸어 같은 기간을 여러 번 받아도 중복이 0건입니다.

DB > transactions
4

내부 API·화면

계좌번호는 뒤 4자리만 남겨 보여 줍니다. 필터, 페이징, CSV 내보내기, 수동 새로고침을 제공합니다.

내부 API > 대시보드
