PROJECT / WEB RPA

웹 반복 작업을
런처 하나로

작업마다 독립된 브라우저 자동화 스크립트를 런처가 실행합니다. 진행 로그는 화면에 실시간으로 보이고 파일로도 남습니다.

Before
주문서 건당 3~5분 등록, 인보이스 건별 다운로드
After
엑셀 주문서 일괄 등록 + 인보이스 일괄 저장
Type
Ops / Web RPA
PythonTkinterSeleniumsubprocessPyInstaller

HOW IT WORKS / 작동 단계

1

입력·검증

로그인 정보, 엑셀 파일, 저장 폴더를 고르면 실행 전에 입력값을 확인합니다.

런처 > 실행
2

주문서 일괄 등록

엑셀 주문서를 읽어 웹에 한 번에 등록합니다.

scripts > 주문 등록
3

인보이스 일괄 저장

지정한 폴더에 인보이스를 자동으로 내려받습니다. 등록과 저장을 이어서 실행할 수도 있고, 앞 단계가 실패하면 멈춥니다.

scripts > 인보이스 저장
4

선택 주문 삭제

잘못 들어간 주문을 골라 한 번에 지웁니다.

scripts > 주문 삭제
5

로그·종료 처리

성공, 건너뜀, 오류를 색으로 구분해 기록합니다. 중지하면 하위 프로세스까지 정리합니다.

런처 > 로그 / 중지

RESULTS / 성과

주문서 등록 (건당)3~5분 → 수 초
인보이스·삭제·오류 추적100% 자동

계정 정보는 명령줄이 아닌 환경변수로 넘겨 프로세스 목록에 드러나지 않게 했습니다.
