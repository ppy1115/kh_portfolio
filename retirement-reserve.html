자동화 시스템 구조

퇴직급여충당금 시스템은 3단계, 총 13개 모듈로 구성됩니다:

Excel VBA 배열 처리 고속 데이터 복사 다중 파일 통합

Stage 1: 초기화 & 데이터 수집

여러 파일에서 데이터를 가져와 작업 환경을 구축합니다.

모듈 1 ▼

초기화 및 파일 불러오기

기산일자 검증, 파일 선택, 고속 데이터 복사

핵심 기능

  • 기산일자 검증: 기산시작일/종료일 필수 입력 확인
  • 파일 사전 검증: Input 테이블과 선택 파일 매칭 (작업 전 검증!)
  • 고속 백업: 당월 → 전월 데이터 배열 복사
  • 다중 파일 가져오기: 여러 엑셀 파일을 한 번에 통합

극한 성능 최적화

× 기존 방식: 워크시트 복사 (느림)
✓ 새 방식: 배열로 한 번에 복사

개선 효과: 90초 → 15초 (83% 단축!)

최적화 기법:
- Application.ScreenUpdating = False
- Application.Calculation = xlCalculationManual
- 배열 기반 데이터 복사
- AutoFit 최소화

파일 검증 로직

1. 사용자가 파일 선택
2. Input 테이블에서 파일명 정확 매칭 확인
3. 하나라도 매칭 안 되면 전체 작업 중단
4. 모든 파일 검증 통과 → 작업 진행

→ 잘못된 파일로 작업하는 실수 원천 차단!
모듈 2 ▼

검증열 추가 및 서식 설정

26개 검증 수식 자동 생성, 사번 처리

자동 생성 검증열 (26개)

  • 전월: 전월 데이터와 비교 (8개 검증)
  • 당월급여: payroll 데이터와 대조
  • 상여 200%: 상여금 계산 검증
  • 적치 검증: 적립금 보상 확인
  • 퇴직금 계산: DC/DB/EXEC별 계산 검증
  • 그룹VS입사자: 그룹사 입사일 vs 회사 입사일
  • 입사VS기산시작일: 입사일 vs 기산일 일치 여부

사번 처리 (15자리 이상)

문제: 15자리 이상 숫자가 지수 표기로 변환됨
예: 123456789012345 → 1.23457E+14

해결: TextToColumns + 숫자 형식 변환
1. Tab 구분자로 TextToColumns 실행
2. 15자리 이상만 텍스트 형식으로 변환
3. 정확한 사번 유지!

자동 처리 항목

  • 그룹사 입사일 매칭 (O열)

Stage 3: 예외 처리 및 최종 검증

데이터 정확도를 보장하는 다층 검증 시스템

검증 1 ▼

인원현황 상이자

인원현황에는 있지만 당월 퇴충에 없는 데이터 추출

동작 원리

1. 인원현황 상이자 시트에서 전체 사번 읽기
2. 당월 퇴충 시트의 숫자 사번을 딕셔너리에 저장
3. 인원현황에는 있지만 당월에 없는 사번 추출
4. VLOOKUP으로 성명 매칭 검증
5. TRUE/FALSE 기준 내림차순 정렬

→ 누락된 인원 자동 감지!

숫자 사번만 처리: 텍스트/문자 사번은 자동으로 무시하여 에러 방지

검증 2 ▼

자매사전입자

신규입사자 중 그룹사/기산일 불일치자 추출

추출 조건

전제조건: M열 = "신규입사"
추출조건: AY열 OR AZ열 중 하나라도 FALSE

AY열: 그룹VS입사자 (그룹사 입사일 ≠ 회사 입사일)
AZ열: 입사VS기산시작일 (입사일 ≠ 기산시작일)

→ 자매사에서 전입한 신규입사자 자동 감지!

결과: "자매사전입자" 시트 자동 생성, 대상자 없으면 "대상자 없음" 표시

검증 3 ▼

예외 사번 검증

DX기준 시트의 예외 테이블 대조

검증 프로세스

  1. DX기준 시트의 "예외" ListObject에서 사번 읽기
  2. 당월 원본(시스템) 시트에서 해당 사번 찾기
  3. 발견/미발견 개수 집계
  4. 결과 메시지로 알림
예외 사번 검증 결과:
총 예외 사번 수: 5건
당월 원본에서 발견: 5건
당월 원본에서 미발견: 0건

발견된 사번: 10001, 10002, 10003...
→ 모든 예외 사번이 정확히 처리되었는지 확인!
