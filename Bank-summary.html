초기화 (표지 데이터 변경)

표지 C열 → D열 복사 + 날짜 변경

자동 처리

1. C4 → D4로 복사 (헤더 포함)
2. D4 헤더: "당월" → "전월" 변경
3. C4 헤더 날짜 업데이트:
   To-be C5 셀 → 'YY년 M월
   
표지!C4 = "당월('25년 9월)"
표지!D4 = "전월('25년 8월)"

증감현황

항목별 합계 자동 계산

배열 처리 (10만행 0.5초)

급여대장_당월 시트:
- 사번 개수 → 증감현황(급여)!C7
- B8부터 항목명 읽기

For 각 항목명:
    급여대장_당월 헤더 검색

    → 증감현황(급여)!C열에 입력

배열로 한번에 처리!
모듈 5 ▼

은행총괄

은행별 집계 + 증감현황 대조 + 차액 계산

5단계 자동 처리

1. KEY 시트 "헤더생성" 테이블에서 열 생성
2. 다중 파일 선택 → "임금유형명" 수집
   → Dictionary로 유니크 값만
3. 항목명 변환:
   Main 시트 "항목명변환" 테이블
   대상값 → 변경값 매핑
4. 은행별 입금액 합계:
   For 각 파일:
       구분별 입금액 Sum
   → 은행총괄표 열에 입력
5. 증감현황 조회 + 차액 계산:
   증감현황(급여) B열 검색
   → 증감제외 항목 차감
   → 차액 = 은행총괄표 - 증감현황

증감제외 로직

  • Main 시트 "증감제외" 테이블 참조
  • 항목명, 항목명2 일치 시 차감
  • 최종 증감현황 = 원본 - 제외 합계

핵심 알고리즘

1. 은행별 집계 (Dictionary)
   For 각 파일:
       For 각 행:
           구분 = 항목명변환(임금유형명)
           If Not dict.Exists(구분):
               dict(구분) = 0
           dict(구분) += 입금액
   
2. 증감현황 계산 (배열)
   항목배열 = B8:B마지막행
   For i = 1 To 항목수:
       열번호 = Find(항목명, 헤더)
       합계 = WorksheetFunction.Sum(열)
       결과배열(i) = 합계
   시트에 한번에 쓰기
   
3. 증감제외 차감
   증감원본 = 증감현황(급여)!C열
   For 각 제외항목:
       If 항목명 or 항목명2 일치:
           증감원본 -= 해당값
   최종증감 = 증감원본
   
4. 차액 검증
   차액 = 은행총괄표 - 최종증감
   If 차액 ≠ 0: 빨간색 표시
