대상자 불러오기

제도전환/중도인출 파일 다중 통합

다중 파일 통합

제도전환 파일들:
- 첫 파일: 헤더 포함
- 나머지: 데이터만 병합
→ "제도전환" 시트 생성

중도인출 파일들:
- 첫 파일: 헤더 포함
- 나머지: 데이터만 병합
- 마지막 열에 "비고" 추가
- 비고 열에 파일명 입력
→ "중도인출" 시트 생성

자동 서식

  • 사번 텍스트 → 일반 형식
  • 가운데 정렬
  • 행높이 12
  • 1행 틀고정
  • 비고 열: RGB(255, 242, 204)

무급부 처리

중도인출무급부/DB무급부 자동 추출

중도인출무급부

조건:
To-be C6-1 ≤ 중간정산일 ≤ To-be D6

헤더:
- 사번, 성명, 고용유형, 사원유형
- 주민등록번호 (텍스트 형식)
- 그룹입사일
- 중간정산일

서식:
- 주민등록번호, 중간정산일: RGB(217, 225, 242)
- 그룹입사일: RGB(68, 114, 196) + 흰색 글씨

DB무급부

조건:
퇴직사유 = "각 사유"

추가 열:
- 뒷자리 ***표시 (주민번호 앞 6자리 + ***)
  배경색: RGB(255, 242, 204)
- 퇴직세트, 승계여부, 전출회사
  배경색: RGB(68, 114, 196) + 흰색 글씨

핵심 성공 요인

1. 다중 파일 통합

  • 제도전환/중도인출 파일 자동 병합
  • 비고 열에 파일명 자동 입력
  • 서식 자동 적용

2. 무급부 자동 추출

  • 날짜 범위 기반 필터링
  • 퇴직사유 기준 검출
  • 주민번호 마스킹

3. 폴더 구조 자동 생성

  • 4단계 폴더 구조
  • 파일 암호화
  • 필요 열만 선택 저장

기술 상세

사용 기술

Excel VBA FileDialog Dictionary ListObject 파일 암호화 FileSystemObject

핵심 알고리즘

1. 다중 파일 통합
   For 각 파일:
       If 첫 파일: 헤더 포함 복사
       Else: 데이터만 병합
   
2. 무급부 검출
   중도인출: C6-1 ≤ 중간정산일 ≤ D6
   DB무급부: 퇴직사유 = "비자발_자매사전출"
   
3. 주민번호 마스킹
   앞 6자리 + String(나머지, "*")
   
4. 폴더 생성
   FSO.CreateFolder(경로)
   파일 암호화: SaveAs Password:=암호
