원천세 자동화 시스템

3-4일 걸리던 원천세 신고 업무를 10분으로 단축시킨 완전 자동화 시스템

4일 -> 5분
성능 개선
99.9%
정확도
6개 모듈
자동화 프로세스

해결한 문제

매월 원천세 신고 기간의 악몽

  • 10개 이상의 raw 파일을 일일이 열어서 복사/붙여넣기
  • 근로소득과 퇴직소득을 수동으로 분리
  • 인원수 검증을 계산기로 일일이 확인
  • 예수금과 데이터를 수동 매칭
  • 실적 검증을 엑셀 수식으로 일일이 입력
  • 10개 파일을 수동으로 저장하고 암호 설정

결과: 매월 높은 에러 위험, 지친 HR팀

5분

6개 모듈 자동 실행

완전 자동화

원천세 자동화는 6개 모듈의 순차 실행으로 구성됩니다:

모듈 0: 초기화 (1초)
   ↓
모듈 1: 전표 실적검증 (1분)
   ├─ 근로/퇴직 데이터 병합
   ├─ 전표 처리
   └─ 실적 집계
   ↓
모듈 2: 인원검증 (20초)
   ├─ 근로소득 인원 검증
   └─ 퇴직소득 인원 검증
   ↓
모듈 3: 예수금 처리 (10초)
   ├─ 예수금 파일 병합
   └─  데이터 매칭
   ↓
모듈 4: 실적검증 (5초)
   └─ 원천세 내역 총합 검증
   ↓
모듈 5: 송부용 파일 생성 (20초)
   └─ 10개 시트 → 10개 암호화 파일
Excel VBA Dictionary 검색 ArrayList 동적 수집 배열 고속 처리 자동 검증 시스템

모듈 상세

모듈 0 ▼

초기화

작업 공간 정리 및 준비

필수 시트만 남기기

남길 시트:
✓ TO-BE (설정값 및 기준 테이블)
✓ 참고시트 (헤더 매핑 정보)
✓ 일용직 (일용직 데이터)

삭제할 시트:
× 근로소득 (이전 달 데이터)
× 퇴직소득 (이전 달 데이터)
× 전표 관련 시트들
× 기타 모든 임시 시트
  • 이전 달 데이터가 남아있으면 새 데이터와 섞임
  • 깨끗한 상태에서 시작해야 에러 방지
  • 파일 용량 절감
모듈 1 ▼

전표 실적검증 (4단계 통합)

근로/퇴직 데이터 통합처리

1-1. 근로/퇴직 시트 생성

List로 데이터 분류

For 각 파일:
    For 각 행:
        If 확정월 == 작업연월:
            If 퇴직지급액 > 0:
                → 퇴직List에 추가
            Else:
                → 근로List에 추가

1-2. 전표 처리

KEY값 생성

KEY값 = 급여월 + 급여카테고리유형 + 사업부코드

예시:
급여월: 2024.11
급여카테고리유형: 정기급여

→ KEY값: "2024.11정기급여"

1-3. 실적 집계

  • Dictionary로 피벗 테이블 생성
  • 당월실적과표 (KEY값별 집계)
  • 산학장학금(과표) 자동 필터링
  • 기타비반복과표상세
모듈 2 ▼

인원검증

근로/퇴직 인원수 자동 검증

근로소득 인원 검증

For 각 행 in 근로소득:
    If 구분 == "퇴직급여":
        키값 = 급여월 + 급여카테고리유형
        Dictionary[키값] += 1

퇴직차수 시트와 매칭:
"2024. 11 정기급여" → "2024.11정기급여"
(공백 제거, 점 제거)

퇴직소득 인원 검증

  • "퇴직금 대상=Y" 필터링 추가
  • 특수 처리 (중도인출 + 제도전환)
  • 검증 = 0이면 일치, ≠0이면 불일치
모듈 3 ▼

예수금 처리

예수금 통합 및 매칭

예수금이란?

회사가 직원 급여에서 미리 떼는 세금:

급여총액: 3,000,000원
원천징수세: 150,000원 (예수금)
실수령액: 2,850,000원

회사가 150,000원을 "예수"하고 있다가
다음달 10일에 세무서에 납부

처리 과정

  • 예수금 파일 병합 (급여/상여/퇴직)
  • raw 당월 원천세 파일 매칭
  • 차이 자동 계산 (원본)
  • ★원천세_근로소득 시트 생성
모듈 4 ▼

실적검증

원천세 내역 총합 검증

H~R열 총합 계산

마지막 행 + 1: "최종 원천세 내역"
H열: =SUM(H1:H{lastRow})
...
R열: =SUM(R1:R{lastRow})

마지막 행 + 2: "★원천세_근로소득"
H열: =★원천세_근로소득!H열합계
...

마지막 행 + 3: "차이"
H열: =H(최종) - H(★원천세)
...

결과: 0 → ✓ 일치, ≠0 → × 불일치

차액확인 시트 생성

  • ★원천세_근로소득
  • ★원천세_퇴직소득
  • 세액정산
  • ★예수금_근로소득
모듈 5 ▼

송부용 파일 생성

10개 시트 → 10개 암호화 파일

송부 대상 시트 (10개)

  1. 근로소득
  2. 근로소득
  3. 세액정산
  4. 당월전표
  5. 일용직
  6. 과표추가
  7. 기타비반복과표상세
  8. 산학장학금(과표)
  9. 예_퇴직소득
  10. 원_퇴직소득

자동 처리

For 각 시트:
    1. 새 엑셀 파일 생성
    2. 시트 복사
    3. 기본 시트 삭제
    4. 파일명 생성: {시트명}(송부)_{년월}.xlsx
    5. 암호 설정 및 저장

예시:
★원천세_근로소득(송부)_2024.11.xlsx 
★예수금_근로소득(송부)_2024.11.xlsx

핵심 성공 요인

1. 철저한 검증 시스템

  • 작업연월 사전 검증: 파일 처리 전 미리 확인
  • 파일명 자동 검증: Input 테이블과 대조
  • 인원수 자동 검증: 근로/퇴직 2단계
  • 실적 금액 자동 검증: H~R열 총합 비교
  • 차액 자동 계산: 불일치 항목 즉시 확인

2. 성능 최적화

  • 배열 사용: 셀 단위 대비 100배 빠름
  • Dictionary 사용: 검색 O(1) - 즉시
  • List 동적 수집: 크기 자동 확장
  • 화면 업데이트 중지: Application.ScreenUpdating = False

3. 모듈화된 구조

  • 각 모듈이 독립적으로 실행 가능
  • 문제 발생 시 해당 모듈만 재실행
  • 유지보수 용이
  • 기능 추가 쉬움

기술 상세

사용 기술

Excel VBA Dictionary (해시맵) ArrayList (동적 배열) Array Processing ListObjects (표) File Dialog (다중 선택) SaveAs (암호화)

핵심 알고리즘

1. List로 데이터 동적 수집
   - 크기 예측 불가능한 데이터 처리
   - Add 메서드로 자동 확장
   
2. Dictionary로 고속 검색
   - Key: KEY값 (급여월+카테고리+사업부)
   - Value: 인원수 또는 금액
   - 검색 속도: O(1)
   
3. 배열로 일괄 처리
   - 한 번에 읽기 → 메모리 처리 → 한 번에 쓰기
   - 성능: 100배 향상
   
4. 정규식 활용
   - "1월", "11월" → 숫자만 추출
   - 기준월과 KEY 데이터 월 비교

배운 점

자동화의 핵심 원칙

  1. 반복되는 작업 찾기: 매월 원천세 신고
  2. 규칙 정의하기: KEY값 규칙, 데이터 분류 규칙
  3. 예외 상황 처리: 특수 처리, 빈 값 처리
  4. 검증 로직 넣기: 인원검증, 실적검증, 차액확인
  5. 성능 최적화: 배열, Dictionary, List 활용

Excel VBA의 무한한 가능성
