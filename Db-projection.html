모듈 2 ▼

추계

추계대상 및 추계사유 자동 판정 (배열 최적화)

8가지 조건부 로직

조건 1: DC가입자 → N, "DC가입자"
조건 2: 사유(사외이사/비상근) → N, 사유
조건 3: DB/혼합형 + 연금변동TRUE + 1년이상 + 사유공란 → Y
조건 4: 1년미만 + "1년미만자(~~이후 입사)" → N, 사유
조건 5: 1년이상 + "1년미만자(~~.01.01 입사)" → Y, "올해 신규가입"
조건 6: DB/혼합형 + 1년이상 + "1년이상자(~~.01.01 입사)" → Y, "작년 신규가입"
조건 7: DB/혼합형 + 1년이상 + 중도인출/임원선임/자매사전입 → Y
조건 8: 이외 → "확인필요" (노란색 배경)

배열 처리로 1만행 0.5초!

자동 정렬

  • 셀배경색 기준 정렬
  • 노란색("확인필요") 행이 최상단

해외주재원

해외주재원 6단계 통합 프로세스

6단계 자동 실행

1. 차년도 임원 시트 생성 (T1 +365일)
2. Input 테이블 기준 파일 취합
3. 해외주재원 확인 업데이트 (파견일 < 기준연도)
4. 당월 주재원 리스트 파일 선택
5. 사번 비교 및 검증
   - 차이인원 / 임원 / DC 구분
   - 정렬
6. 요약표 생성
   - tmp 당월주재원list 인원
   - 해외주재원 추계 인원
   - 임원/DC/차이인원 집계

모듈 7 ▼

명부양식

명부 양식 자동 채우기

KEY 시트 기반 자동 채우기

KEY 시트 "손해보험명부" 테이블:
- 헤더명, 기준열, 참고시트, 참고열, 가져올값, 수식

3단계 처리:

1. 기준열 빈칸인 경우:
   참고시트[가져올값] → 명부양식[B열부터]
   (헤더 제외, 2행부터 → 6행으로)

2. 기준열 있는 경우:
   Dictionary 고속 검색 (O(1))
   기준열 값 → 참고시트[참고열] 매칭
   → 가져올값 복사

3. 수식 있는 경우:
   6행부터 수식 채우기
   FillDown으로 마지막 행까지

성능 최적화

  • Dictionary 사용 (O(1) 검색)
  • 배열 처리
  • 10만행 3~5초

기술 상세

사용 기술

Excel VBA 배열 처리 Dictionary ListObject 조건부 로직 파일 암호화

핵심 알고리즘

1. 추계 판정 (배열 최적화)
   For i = 1 To 행수:
       8가지 조건 체크
       arr추계대상(i) = 결과
       arr추계사유(i) = 사유
   
   시트에 한 번에 쓰기
   확인필요 행만 노란색
   
2. 해외주재원 검증
   For 각 주재원:
       If Not In 추계: 차이인원
       Else If 임원: 임원
       Else If DC: DC
   
3. 명부 채우기
   Dictionary[기준값] = 가져올값
   배열 조회 → 한 번에 쓰기

배운 점

"복잡한 조건부 로직도 배열 처리로 초고속 실행"
- 8가지 조건을 배열로 처리하여 1만행을 0.5초 만에 완료했습니다.
