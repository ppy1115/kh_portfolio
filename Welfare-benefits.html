해결한 문제

모듈 1 ▼

카드 업로드

카드 파일 → 양식 매핑 + 가공

자동 매핑

KEY 시트 "헤더명" 테이블 기반:
- 대상헤더명 ↔ 가져올헤더명
- 고정값 자동 입력

필수입력값: 입사 → D, 퇴직 → U
법정생년월일+성별: 7자리만
휴대전화번호: - 제거, 첫자리 0 확인
입사일자/퇴직일자: YYYYMMDD 형식

임원구분 자동 판정

  • 직위 → 임원 테이블 검색
  • 임원제외사번 체크
  • Y/N 자동 설정

모듈 4 ▼

부임

부임자 처리

3단계 자동 처리

1. 부임 vs 부임2 비교
   부임2에 없는 사번 → "부임" 표시

2. 부임 vs 귀임 비교
   - Reason = "Proceeding" → "부임"
   - 그 외 → "확인필요"

3. 서식 자동 적용
   - LG스마트체 Regular, 크기 9
   - 가운데 맞춤, 행높이 12
   - 첫 행 고정
모듈 5 ▼

포인트 검증

사번 기준 매칭 + 합계 검증

자동 검증

입사 시트:
- 사번으로 기본포인트 조회
- ERP 열에 총지급포인트 입력
- 검증: 기본포인트 = ERP?

총합계 검증:
총지급포인트 = 입사기본 + 복직지급

→ 일치: True
→ 불일치: False + 차이 표시

핵심 성공 요인

1. 이중 업무 통합 자동화

  • 수시부여: 입사/복직/FSE 부임 포인트 지급
  • 퇴직정산: 퇴직자 포인트 회수
  • 하나의 시스템으로 통합 관리

2. 다중 플랫폼 업로드

  • 카드 업로드 자동 생성
  • 복지몰 업로드 자동 생성
  • ERP 업로드 자동 생성

3. 자동 검증 시스템

  • 포인트 합계 자동 검증
  • 과표/공제 자동 검증
  • True/False 즉시 표시

기술 상세

사용 기술

Excel VBA FileDialog Dictionary ListObject 조건부 로직 데이터 검증

핵심 알고리즘

1. 카드 업로드
   KEY 시트 헤더명 테이블 기반 매핑
   고정값 자동 입력
   임원구분 자동 판정
   
2. 부임 검증
   부임 vs 부임2 차집합
   부임 vs 귀임 교차 검증
   Reason 기준 판정
   
3. 포인트 검증
   For 각 사번:
       기본포인트 ↔ ERP 매칭
       검증 = (기본 = ERP)
   
   총합계 = 총지급 - (입사기본 + 복직지급)
   
4. 퇴직정산 검증
   For 정산일자 공란:
       과표추가 → 시스템과표
       기타공제 → 시스템공제
       
       과표검증 = (최종과표 = 시스템과표)
       공제검증 = (급여공제 = 시스템공제)

배운 점

"복잡한 이중 업무도 하나의 시스템으로 통합 자동화"
