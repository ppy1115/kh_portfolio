파일불러오기

Input 테이블 기반 파일 검증 및 가져오기

사전 검증 시스템

1. 사용자가 여러 파일 선택
2. Input 테이블에서 파일명 확인
3. 하나라도 없으면 전체 작업 중단
4. 모든 파일 검증 통과 → 가져오기 시작

→ 잘못된 파일로 작업하는 실수 원천 차단!

자동 처리

  • 확장자 제거하여 Input 테이블과 비교
  • 파일명 → 시트명 매핑
  • 동일 시트명 있으면 자동 삭제 후 재생성
  • 모든 시트 첫 번째 시트 데이터 복사

상이자 (지도직 검증)

지도직 사원의 근태 상이자 자동 검출

지도직 상이자 검출 로직

근태현황 시트에서:
1. "사원구분" = "지도직" 필터링
2. 시트 "지도직검증" 표의 "헤더명" 열 참조

특근검증

다중 특근 파일 통합 및 상이자 검출

특근 파일 통합

1. 다중 파일 선택창 표시
2. 첫 파일: 헤더 포함 복사
3. 나머지: 데이터만 추가
4. "특근 합체" 시트 생성

KEY 시트 "특근합체" 표 기준:
- 필요한 열만 남기고 나머지 삭제
- Dictionary로 빠른 확인

10분 상이자 검출 (최적화)

정렬 후 삭제 방식 (서식 보존 + 고속):

1. 시트 복사 (원본 보존)
2. "특근시간" 열의 소수점 체크
3. 일치하는 행에 "삭제표시" 컬럼 추가
4. 정렬 (삭제표시 기준)
5. 삭제 대상 한번에 삭제

→ 10만 행 기준 2~4초!

사번 숫자 변환

  • TextToColumns로 텍스트 → 숫자
  • 헤더 배경색: RGB(217, 217, 217)
  • 결과 시트: "10분 상이자"

1. 상이자 검출 (지도직)

           합계 = 지도직검증표_헤더들의_합
           If 합계 ≠ 0:
               → 상이자 시트에 복사
   
2. 10분 상이자 검출 (최적화)
   특근시간 소수점 6자리
   
   정렬 후 삭제 방식:
   ① 삭제 대상에 표시
   ② 표시 기준으로 정렬
   ③ 한번에 삭제

3. 배열 처리 (대량 데이터)

4. Dictionary 고속 검색

   If dict.exists(key): 처리
   → O(1) 검색 속도
