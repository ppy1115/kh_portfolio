ERP 화면에서 계좌마다 즉시조회를 누르고 내역을 옮겨 적던 일을 자동화했습니다. 계좌 49개와 일주일 치 거래 수집이 30초 안에 끝납니다.

After
자동화
즉시조회 · 수집 · 자금일보 작성 자동

Python · Playwright · SQLite · ERP 내부 API

01

작동 방식

1

화면 구조 분석

ERP 공개 API에는 즉시조회 기능이 없어, 화면이 실제로 호출하는 내부 API 구조를 직접 분석했습니다.

경로분석 도구 > 통신 캡처

2

즉시조회 실행

기간(오늘·3일·7일·14일·30일)을 고르고 버튼을 누르면 전 계좌의 즉시조회를 실행하고 완료될 때까지 기다립니다.

경로자금일보 > 즉시조회 + 수집

3

내역 수집·누적

입출금 내역과 잔액을 모아 DB에 누적합니다. 처음 설정할 때는 1개 계좌로 먼저 시험해 계좌 잠김을 막습니다.

경로수집기 > DB 적재

4

자금일보 화면

일자별 자금 흐름, 사업장별·계좌별 기간 요약을 표로 보여 주고, 필터와 합계는 화면 위에 고정됩니다.

경로자금일보 > 요약 표

5

엑셀·포털 연동

사업장별 자금일보 엑셀 양식을 자동으로 채우고, 사내 포털 재무 탭에서도 같은 화면을 엽니다.

경로포털 > 재무
