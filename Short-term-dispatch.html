기술 상세

사용 기술

Excel VBA FileDialog 다중 파일 통합 Dictionary VLOOKUP ListObject 조건부 서식

핵심 알고리즘

1. Input 테이블 순서 처리
   Dictionary: Key=Input순서, Item=파일경로
   정렬 후 순차 처리
   
2. 상이자 검출 (3단계)
   ① 파견시작일자 vs 발령일자
   ② 파견복귀일자 vs 복귀 발령일자
   ③ 복귀일자 ≤ 기산일 AND 복귀 발령 공란
   
3. 환차손 계산
   환율 = VLOOKUP(통화, 환율테이블)
   환차손 = 원화금액 - (외화금액 × 환율)
   
4. 비용코드 생성
   급여항목별 자동 매핑

배운 점

복잡한 급여 업무 자동화

  1. 단계 검증: 인원 대사 → 상이자 → 환차손
  2. 파일 통합: Input 테이블 순서 기반
  3. 상이자 검출: 3단계 조건 로직
  4. 환율 처리: VLOOKUP 자동 계산
