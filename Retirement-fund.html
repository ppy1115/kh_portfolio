해결한 문제

연 2회 (6월/12월) 퇴직연금 적립, 복잡한 수작업의 늪

  • 9개 연금사 명부 파일을 일일이 열어서 대조
  • 인원 검증을 수동으로 일일이 확인
  • 금액 검증을 여러 단계로 반복 수행
  • 항목별 계산 로직이 복잡하고 실수 위험 높음
  • 중도인출 실적 확정 및 연금사별 집계
  • 연금사별 송부 파일 9개 생성 및 암호 설정

결과: 매번 4일 소모, 높은 에러 위험, 복잡한 검증 과정

├─ 모듈 5: 항목별 계산 (급여명세 기반)

├─ 모듈 7: 금액검증 최종 (2차)

Stage 1: 초기화 & 데이터 수집

모듈 0 ▼

초기화

날짜 검증 및 시트 정리 (6월/12월 체크)

날짜 검증 (가장 먼저 실행)

Main 시트 B4셀 날짜 확인:
- 6월 또는 12월만 작업 가능
- 그 외 월: 즉시 중단 + 경고 메시지

"상반기 적립 : 6월
하반기 적립 : 12월 입니다.
작업년월 재확인 바랍니다."

보존 시트 (13개)

✓ Main, KEY, report, 계산내역_최종
✓ 9개 연금사 시트

시트명 변경 및 report 정리

  • 계산내역_최종 → 직전 적립 대상자
  • report H,I열 → F,G열 값 복사
  • A1셀 제목: "YYYY년 상/하반기 DC 정기불입"
  • F6~J6 헤더: 연도 및 상/하반기 동적 표시

연금사 명부

9개 연금사 명부 파일 가져오기

각 연금사에서 받은 명부 파일을 시스템에 불러옵니다.

  • 다중 파일 선택 지원
  • 파일명 검증
  • 시트 자동 생성
모듈 2 ▼

파일불러오기 인원검증

Input 테이블 기반 파일 검증 및 가져오기

사전 검증 시스템

1. 사용자가 여러 파일 선택
2. Input 테이블에서 파일명 확인
3. 하나라도 없으면 전체 작업 중단
4. 모든 파일 검증 통과 → 가져오기 시작

→ 잘못된 파일로 작업하는 실수 원천 차단!
모듈 3 ▼

인원검증

Dictionary 기반 고속 인원 대조

Dictionary 고속 검색

1. 연금사 명부의 사번을 Dictionary에 저장
2. 우리 시스템 사번과 대조
3. 일치 여부 즉시 확인 (O(1) 검색)

장점:
- 10만 건 데이터도 1초 이내 처리
- 누락 인원 즉시 감지
- 중복 인원 자동 검출

Stage 2: 계산 & 검증

모듈 5 ▼

항목별 계산

급여명세 기반 불입액 자동 계산

DC형 vs DB형 계산 로직

DC형 (확정기여형):
불입액 = 급여명세 합계

DB형 (확정급여형):
불입액 = 계산식 기반 자동 산출

임원:
별도 계산 로직 적용
  • 급여명세 데이터 자동 매칭
  • 조건부 계산 로직
  • 예외 사항 자동 처리

계산된 금액 1차 검증

검증 항목

  • 계산 금액 vs 명세 금액
  • 합계 금액 일치 여부
  • 이상 금액 감지
  • 누락 인원 확인
모듈 7 ▼

금액검증 최종 (2차)

최종 금액 확정 전 2차 검증

다층 검증 시스템

1차 검증: 계산 로직 확인
2차 검증: 연금사 명부와 대조
최종 검증: 총합계 일치 확인

불일치 발견 시:
- 해당 인원 자동 표시
- 차액 금액 표시
- 원인 분석 정보 제공

실적확정 (중도인출 최종)

중도인출 데이터 반영 및 실적 확정

중도인출 처리

1. 중도인출 파일 다중 선택
2. Input 테이블 검증
3. 첫번째 시트 가져오기
4. 시트명 자동 변경

헤더 3개 입력:
- AH1: 기관
- AI1: 개수

  • COUNTIFS로 개수 집계
  • SUMIFS로 금액 집계
  • report 시트 자동 반영

모듈 11 ▼

파일생성

9개 연금사별 암호화 파일 생성

임시 파일 전략 (안정성 강화)

1단계: 임시 파일로 저장
For 각 연금사:
    시트 복사 → _temp_1.xlsx로 저장
    암호 설정
    Dictionary에 임시경로:최종경로 저장

2단계: 일괄 이름 변경
For 각 임시 파일:
    _temp_1.xlsx → 연금사별_정산내역.xlsx
    
→ 파일명 특수문자로 인한 오류 방지!

파일명 정리 함수

CleanFileName 함수:
제거 대상: \ / : * ? " < > |
보존 대상: [ ] (대괄호는 유지)

예시:
원본: 2025년_연금사별_정산내역
결과: 2025년_연금사별_정산내역 (대괄호 유지)

자동 처리

  • Main 시트 C4: 암호
  • Main 시트 D4: 파일명 템플릿 (ex. YYYY년_{연금사명}_정산내역)
  • KEY 시트 "송부" 표 "연금사명" 열 참조
  • 폴더 선택 대화상자
  • 성공/실패 개수 리포트

핵심 성공 요인

1. 철저한 사전 검증

  • 날짜 검증: 6월/12월만 작업 가능하도록 원천 차단
  • 파일 검증: Input 테이블과 대조하여 작업 전 확인
  • 인원 검증: Dictionary로 빠른 대조
  • 금액 검증: 2단계 검증 시스템

2. 성능 최적화

  • Dictionary 활용: O(1) 검색 속도
  • 배열 처리: 대량 데이터 고속 처리
  • 화면 업데이트 중지: ScreenUpdating = False
  • 임시 파일 전략: 안정적인 파일 생성

3. 파일 생성 안정성

  • 임시 파일 먼저 생성 후 일괄 이름 변경
  • 파일명 특수문자 자동 제거
  • 암호 설정 자동화
  • 성공/실패 개수 자동 리포트

기술 상세

사용 기술

Excel VBA Dictionary (해시맵) FileDialog 다중 파일 통합 조건부 계산 COUNTIFS / SUMIFS 암호화 저장

핵심 알고리즘

1. Dictionary 고속 검색
   사번 → 인원 정보 매칭
   검색 속도: O(1) - 즉시
   
2. 임시 파일 전략
   Step 1: _temp_N.xlsx로 안전하게 저장
   Step 2: 최종 파일명으로 일괄 변경
   → 파일명 오류 원천 차단
   
3. 날짜 검증 로직
   Split(B4셀, "-")(1) → 월 추출
   If 월 != 6 AND 월 != 12: 즉시 중단
   
4. 퇴직연금기관 집계
   Dictionary로 유니크 기관 추출
   COUNTIFS / SUMIFS로 집계
   report 시트 자동 반영

배운 점

정기 업무 자동화의 핵심

  1. 사전 검증: 날짜/파일/데이터 검증으로 에러 원천 차단
  2. 성능 최적화: Dictionary, 배열로 대량 데이터 고속 처리
  3. 안정성 강화: 임시 파일 전략으로 파일 생성 오류 방지
  4. 다층 검증: 인원 검증 + 금액 검증 2단계
  5. 자동 리포트: 성공/실패 개수 자동 집계
