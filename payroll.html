모듈 1 ▼

파일 불러오기

Main 시트 Input 테이블 기반 다중 파일 검증 및 가져오기

사전 검증 시스템

1. 사용자가 여러 파일 선택 (MultiSelect)
2. Input 테이블에서 파일명 확인
3. 하나라도 없으면 전체 작업 중단
4. 모든 파일 검증 통과 → 가져오기 시작

→ 잘못된 파일로 작업하는 실수 원천 차단!

자동 처리

  • 확장자 제거하여 Input 테이블과 비교
  • 파일명 → 시트명 매핑 (Trim 처리)
  • 동일 시트명 있으면 자동 삭제 후 재생성
  • 모든 시트 첫 번째 시트 데이터 복사

급여정보 시트에서 당월 급여 대상자를 추출하여 "당월 대상자" 시트에 정리합니다.

  • 필수 필드 검증
  • 사번 기준 정렬
모듈 3 ▼

대상자 검증

전월 vs 당월 대상자 비교 검증

3단계 검증 프로세스

  1. 열 필터링: KEY 시트 테이블 기반 필요 열만 남김
  2. 당월 데이터 복사: "당월"에서 지정 열 복사
  3. 비교 열 삽입: 전월 vs 당월 자동 비교 수식 생성
비교 열 수식:
vs열 = 전월열 = 당월열

헤더 배경색:
- 기존 헤더: RGB(217, 217, 217)
- 비교 열: RGB(91, 155, 213) + 흰색 글자

서식 적용

  • O1:R1 배경색: RGB(226, 239, 218)
  • 전체 가운데 정렬
  • 틀 고정: 2행

검증(재계산)

지도직 사원 추출 및 시간외수당 자동 계산

동적 수당 수식 적용

KEY 시트 "정보" 표의 "수당" 열 참조
→ 동적으로 수당 항목 찾아 수식 적용

시간외수당 수식:
=ROUND(임금/226*1.5*고정OT,-3)

각 수당 수식:
=ROUNDUP(수당*20/12,0)

근무일수 계산

  • Main 시트 "일자" 테이블 참조
  • 임원 vs 임원 외 구분
  • 일자 종료일자 고려
  • 업로드파일 '비고' 자동 생성

핵심 성공 요인

1. 철저한 사전 검증

  • 파일 검증: Input 테이블과 대조하여 작업 전 확인
  • 시트 존재 확인: 필수 시트 누락 시 즉시 알림
  • 데이터 무결성: 전월 vs 당월 자동 비교
  • 조건부 검증: 7월 외 선택적복리후생 경고

2. 동적 처리 시스템

  • KEY 시트 기반: 코드 수정 없이 테이블만 수정
  • ListObject 활용: 표 구조 자동 인식
  • Dictionary 검색: 빠른 데이터 매칭
  • 조건부 수식: 상황에 맞는 계산 로직

3. 완벽한 서식 자동화

  • 글꼴, 크기, 색상 일괄 적용
  • 회계 형식 자동 적용
  • 가운데 정렬, 테두리
  • 열 너비 자동 조정

기술 상세

사용 기술

Excel VBA Dictionary (해시맵) ListObject (표) FileDialog 다중 파일 통합 VLOOKUP / Match 조건부 서식 TextToColumns

핵심 알고리즘

1. 파일 사전 검증 시스템
   - Input 테이블 읽기
   - 선택 파일 확장자 제거
   - 매칭 확인 → 실패 시 전체 중단
   
2. 동적 열 참조
   - IsExcelColumn 함수로 A, AU 등 판별
   - 엑셀 열: 데이터 복사
   - 텍스트: 반복 입력
   
3. Dictionary 활용
   - 헤더명 → 열 번호 매핑
   - 사번 → 데이터 매칭
   - O(1) 검색 속도
   
4. 조건부 데이터 추출
   - KEY 시트 기준 테이블 참조
   - 복잡한 조건 자동 판별
   - 필터링 후 새 시트 생성

배운 점

복잡한 업무 자동화의 핵심

  1. 모듈화: 13개 모듈로 분리하여 유지보수 용이
  2. 데이터 중심 설계: KEY 시트로 모든 설정 관리
  3. 에러 방지: 사전 검증으로 문제 원천 차단
  4. 사용자 친화적: 파일/폴더 선택 대화상자
  5. 완벽한 서식: 일관된 디자인 자동 적용
